# AMB's description (checked by tools/fake_run4.py desc: frames, labels, counts, the hash, the parameters PROTOCOL.md
# lists), sets parameters, fires actions, gets the values back as they change (its own and the device's knobs), the
# errors; the clock has the transport while it runs; the player switches modes on the device; Synth mode's
